# Reservoir Simulation

This workstream covers the higher-fidelity numerical reference environment and AURORA's integration with it. The current direction uses OPM Flow with the EGG reservoir model.

Documentation should define installation/environment, exact model/version, wells and controls, simulator inputs/outputs, observation extraction, action application, timestep/control interval, repeatable scenarios, failure handling, and modifications made by the team.

The simulator is a controlled numerical reference environment. It is not physical-field ground truth.
