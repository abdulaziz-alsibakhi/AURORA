# Experiments & Results

AURORA experiments should answer explicit questions under reproducible conditions. Planned comparisons include suitable baselines and controller/safety variants, potentially including baseline control, feed-forward control, recurrent control, and recurrent control with the safety layer.

Candidate metrics include cumulative extraction/production objectives, pressure behavior, constraint violations, safety interventions, model mismatch, and robustness on unseen conditions. Exact metrics and baselines must be justified and frozen before final evaluation.

Every important result should be traceable to its scenario, configurations, simulator/model version, code revision, seeds where relevant, and stored evidence.
