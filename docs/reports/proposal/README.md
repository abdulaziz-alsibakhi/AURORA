# AURORA Project Proposal

This directory contains the working LaTeX source for AURORA's Fall project proposal.

The proposal is a formal course deliverable, but it is not a second source of truth for the live project. Its content should be derived from canonical engineering documentation and cited evidence.

As AURORA evolves after proposal submission, consequential deviations should be recorded through the project's change/decision process and reconciled in later reports.

## Working rule

**Do the engineering once; explain it clearly in the proposal.**

Avoid maintaining independent technical facts in both the proposal and canonical specifications when a reference or generated summary is sufficient.

## Current status

The proposal structure has been initialized. Technical content remains intentionally incomplete until the corresponding roadmap work is justified and reviewed.

An official course/supervisor proposal template or sample, if later provided, should be treated as a compliance input and reconciled against this structure rather than copied blindly.
