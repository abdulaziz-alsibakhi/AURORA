\begin{abstract}
AURORA is a Software/Computer Engineering capstone project investigating autonomous,
closed-loop reservoir control under partial observability and model uncertainty.
This proposal defines the engineering problem, intended system, requirements,
alternatives, feasibility, validation strategy, project plan, and expected evaluation.
The proposal deliberately distinguishes the software-engineering contribution from
the reservoir-engineering application domain and limits claims to those supportable
by the project's eventual evidence.
\end{abstract}
