# Reports & Presentations

This workstream tracks formal capstone deliverables and the evidence needed to support them. Material may cover objectives, motivation, architecture, alternatives, functional/non-functional requirements, use cases, milestones, feasibility, usefulness, risks, cost, Software/Computer Engineering relevance, responsibilities, implementation, experiments, results, limitations, and validation.

Formal reports should reuse the repository's technical sources rather than becoming a disconnected second version of the project.
