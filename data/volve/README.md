# Volve

Volve is a real-field dataset resource available to the team. The complete dataset is intentionally not stored in this Git repository.

Before AURORA relies on it, characterize its authoritative source, local/external storage location, size, time coverage, well identifiers, producer/injector classification where applicable, variables, units, sampling, missing-data characteristics, preprocessing, and exact role in AURORA.

`sample/` is reserved for a small representative subset only where redistribution permits.

Volve must not be treated as interchangeable with the EGG/OPM numerical simulation environment. Their experimental roles are distinct and must be stated explicitly.
