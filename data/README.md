# Data

This directory documents data used by AURORA. **Do not commit large raw datasets directly to normal Git history.**

Repository data material should make it possible to understand what a dataset is, where it came from, which version/subset is used, relevant fields and units, preprocessing, how it is obtained/placed locally, and exactly how AURORA uses it.

Small representative samples may be committed only when redistribution permits and the files are genuinely useful for development/reproducibility.
